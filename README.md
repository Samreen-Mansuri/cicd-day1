# CI/CD Day 1 — Automated Test Pipeline

![CI](https://github.com/Samreen-Mansuri/cicd-day1/actions/workflows/ci.yml/badge.svg)

A beginner-friendly Continuous Integration pipeline built with **GitHub Actions**.
On every push, it automatically:
- sets up Python
- installs dependencies
- runs unit tests with pytest
**Tech:** Python · pytest · GitHub Actions
